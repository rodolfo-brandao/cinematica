Grounding tools

Oito ferramentas expostas ao Claude durante o estágio query. Quatro só leem o grafo; quatro escrevem nele sob demanda.

LEITURA
get_schema
Devolve o schema real do grafo. Chamada antes de escrever Cypher, para o modelo não adivinhar nomes de propriedades.
resolve_entity
Nome livre vira nós candidatos por full-text. Tolera caixa e grafia, onde o match exato falharia em silêncio.
run_cypher
Roda Cypher de leitura. O erro do Neo4j volta estruturado, como insumo para o modelo se corrigir.
vector_search
Filmes semanticamente próximos de um tema, para perguntas que Cypher não expressa.
ESCRITA · SOB DEMANDA
search_external_movie
Procura no TMDb um filme ausente do grafo e devolve candidatos com o tmdb_id.
ingest_movie
Traz esse filme para o grafo. No-op se ele já existir, para nunca sobrescrever o registro vindo do IMDb.
fetch_reviews
Busca as reviews públicas do TMDb para o próprio modelo ler e julgar.
save_movie_sentiment
Persiste o veredito do modelo: nós Review mais o agregado no Movie.
A escrita nunca passa pelo Cypher. run_cypher rejeita qualquer cláusula de escrita por denylist, valida com EXPLAIN antes de executar e roda no modo READ da sessão — a guarda autoritativa. As duas rotas de escrita são as ferramentas dedicadas acima.
