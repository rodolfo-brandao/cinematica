Pipeline de ingestão
Offline, rodado por python -m src.main. Nada é carregado inteiro na memória: os datasets são lidos linha a linha.
Datasets IMDb
4 × .tsv.gz
TMDb API
/movie/{id} + keywords
Ollama
nomic-embed-text
compile.py
compile
Monta índices em memória a partir dos 4 datasets.
→ índices por tconst
enrich.py
enrich
TMDb async, semáforo de 20, retry com tenacity.
→ shards JSONL
consolidate.py
consolidate
Concatena os shards em ordem determinística.
→ data/movies.jsonl
load.py
load
MERGE em lote de nós e relações tipadas.
→ grafo no Neo4j
embed.py
embed
Vetoriza os overviews e cria o índice vetorial.
→ overview_embedding
Retomável
Os shards são nomeados a partir dos tconst ordenados, então um chunk sempre mapeia para os mesmos filmes. Shards que já existem são pulados — dá para rodar em lotes com python -m src.main 200 e continuar depois.
Idempotente
Toda escrita no Neo4j é MERGE, e o embed só busca filmes que ainda não têm vetor. Reexecutar sobre a mesma entrada — ou sobre uma que cresceu — não duplica nada nem refaz trabalho.
