Pipeline do agente

query
Loop de tool-use (8 iterações): escreve Cypher e conserta a partir dos erros reais.
verify
As linhas satisfazem todas as restrições da pergunta?
compose
Redige a resposta usando só as linhas verificadas.
fallback
